Privacy Policy

Last updated: 21 November 2026

Who uses this app

KGVerse AutoClipper is a personal tool used only by its owner on the owner's own computer. It has no other users.

What data it accesses

When the owner connects TikTok, the app receives the TikTok account's basic profile information (an account identifier, display name and avatar) and the permissions the owner approves (for example, uploading videos to the owner's own account). It does not access other people's accounts or private messages.

Where data is stored

Sign-in tokens and settings are stored only on the owner's computer, in a file readable only by the owner's user account. Nothing is stored on this website. This website does not use cookies, analytics or trackers.

Sharing

No data is sold, shared or sent to third parties. Data is only exchanged with the platform the owner connects (for example TikTok), through that platform's official API.

The sign-in page

After the owner approves access on TikTok, TikTok returns a one-time code to callback.html. That page only shows a button that passes the code to the app running on the owner's own computer. The code is not stored or sent anywhere else.

Deleting data / revoking access

The owner can disconnect TikTok in the app at any time (this revokes the app's access and deletes the stored tokens), and can also remove the app in TikTok's settings under Security → Manage app permissions.
